# NETRA — Network Exploitation & Threat Recognition Analysis

🚀 **Smart India Hackathon (SIH) Team Project**
## 📌 About the Project

NETRA is a project exploring how artificial intelligence and network analysis can help connect fragmented information and identify relationships between entities to support criminal network investigations.

## ✨ Key Features

- Network graph visualization
- Entity and relationship analysis
- Document ingestion and case investigation
- AI-assisted insights and alerts

## 🛠️ Areas Explored

- Artificial Intelligence
- Cybersecurity
- Knowledge Graphs
- Network Analysis

## 🎯 Learning Outcomes

- Understanding real-world technology problem-solving
- Exploring AI applications in cybersecurity
- Team collaboration and project presentation
